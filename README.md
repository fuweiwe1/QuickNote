# 晾一会 · QuickNote 0.3

一根自动收进 Windows 11 屏幕顶部的晾衣绳，类似早期 QQ 的贴边收纳。移到顶部边缘展开，鼠标离开后自动收起；展开时浮在普通应用窗口上方。左侧是草稿本，其余是文字和图片便签，没有导航、搜索栏、说明卡片、翻页按钮或撤销提示。

## 下载与更新

首次使用可直接下载单个 EXE，无需压缩包：

| 下载项 | 说明 |
| --- | --- |
| [免安装版](https://github.com/fuweiwe1/QuickNote/releases/latest/download/QuickNote-win-x64-Portable.exe) | 自带运行环境，下载后直接运行。 |
| [精简版](https://github.com/fuweiwe1/QuickNote/releases/latest/download/QuickNote-win-x64-Small.exe) | 需要 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)。 |

0.2 及更早版本尚无更新入口，这次先从系统托盘退出旧版，再下载运行一次 0.3 的 EXE。原有便签保留，不用搬迁数据。从 0.3 起，在 **草稿本右键菜单 / 系统托盘 → 检查更新… → 下载并重启** 中更新即可，不再手动下载压缩包。

支持 Windows 11 x64，原生 WPF，无需账户，便签保存在本机。构建未进行商业代码签名。正式版本通过 Releases 分发，Actions 检查结果默认保留 30 天。

## 使用

1. 在微信、浏览器或其他应用里复制文字或图片。
2. 点击左侧草稿本，把当前剪贴板夹成一张便签。也可以按 **Ctrl+Alt+V**。
3. 鼠标移到屏幕顶部边缘展开绳子，再移到便签上放大；点 **复制** 取用，按钮短暂显示“已复制”。
4. 双击便签或点 **展开** 查看全文、编辑文字，或查看图片。图片详情支持 Ctrl+滚轮缩放。
5. 点 **×**，便签会撕成两半并直接删除，没有撤销提示。

按住便签的纸面并移动，完整卡片跟随鼠标；松开时自动夹到绳子对应的横向位置，并保存位置。其他卡片保持原位，拖到屏幕外会夹在绳子最近的可用端点，左侧草稿本区域保留。手动位置按相对比例保存，重启和分辨率变化后继续保留。

拖入图片也可以收录。没有横向滚动或翻页：未手动定位的便签少时自然留白，放不下时自动重叠，完整便签仍在屏幕两端以内。便签尺寸为 154×216 个逻辑像素，绳子随所在显示器的完整宽度伸展，夹子沿绳子的弧度排列。

**右键草稿本或绳子**可新写便签、选择显示器、打开数据目录或退出。这些操作也在系统托盘中，不占桌面界面。

## 顶部自动收纳

启动时整根绳子收在屏幕上方。鼠标到所选显示器顶部约 3 个逻辑像素的边缘区域后，绳子向下滑出并自动浮在其他普通应用上方，不会抢走输入焦点。离开展开区域约 0.2 秒后，整体向上滑出，完成后完全隐藏，不留下说明面板或导航。

移回展开区域会取消收起。拖动卡片、右键菜单、打开详情、编辑文字或检查更新时暂停自动收起，操作结束再开始计时。没有置顶开关，也不用手动选择显示层级。即使使用 Win+D / Win+M 返回桌面，屏幕顶部触发仍然有效，窗口在展开时恢复正常状态。退出请使用右键或托盘菜单。

## 应用内更新

只有手动选择“检查更新…”时访问本仓库的 GitHub Releases；不上传便签或剪贴板。更新源必须是本仓库的正式版本，保留当前精简版 / 免安装版类型，下载时显示进度并支持取消。

下载完成后校验预期大小及 SHA-256。更新助手确认更新文件和目标目录后，当前版本才会退出；助手等待旧进程退出，再原子替换当前 EXE，保留 `.previous` 上一版本备份。新版正常启动后完成交接；若启动失败则尝试恢复并重新打开旧版。应用目录不可写、下载失败、校验失败或助手未就绪时，原程序继续运行。

更新只替换程序 EXE，不替换便签、图片或偏好文件。安装目录应由当前用户可写，更新不会请求管理员权限。临时更新文件保存在本地数据目录的 `updates/` 中，七天前的临时目录在后续更新时清理。备份程序位于当前 EXE 的同目录。

发布新版本时修改项目版本与 `RELEASE_NOTES.md`，推送对应 `v版本号` 标签；Windows 检查、两种打包和真实更新交接检查通过后，工作流会发布带 SHA-256 信息的正式 Release。

默认使用主屏，副屏可在右键菜单中选择。绳子横跨所在显示器的左右两端，分辨率、缩放或连接变化时重新适配；目标屏断开后回到主屏。Windows 关闭动画效果时立即展开或收起。Windows 11 真机验收项见 [清单](docs/windows-checklist.md)。

## 本地数据

便签内容保存在 `%LOCALAPPDATA%\QuickNote\`：

```text
notebook.json       文字、顺序、图片引用和显示器偏好
notebook.json.bak   上一次保存的恢复备份
images/             独立的图片副本，不依赖聊天记录或原文件
```

只在点击草稿本或使用收录快捷键时读取剪贴板，不监听聊天记录，不上传内容。数据是普通本地文件，没有额外加密。退出后复制整个目录可备份，还原前也应先退出应用。

修改先写入临时文件并刷新，再替换主文件。保存失败保留原状态；主文件损坏时尝试从上一次备份恢复并保留损坏原文件。两份文件都无法读取时停止加载，避免空数据覆盖。

删除从当前便签清单立即移除；恢复备份可能暂时保留相关内容，未被当前或备份引用的图片在后续启动时清理。完全移除数据时，退出后删除整个目录。

图片支持 PNG、JPG/JPEG、BMP、GIF、TIFF，动图或多页图片取第一帧，转换为本地 PNG。单张最多 32 MB、3200 万像素。文字最多 10 万个 UTF-16 代码单元，保留空格与换行。

## 开发与验证

Windows 11 + .NET 10 SDK：

```powershell
dotnet build src/QuickNote/QuickNote.csproj -c Release
dotnet run --project src/QuickNote
dotnet run --project tests/QuickNote.Core.Tests -c Release
./scripts/package.ps1
```

Linux 可交叉编译并运行存储和布局检查；运行 WPF 需要 Windows。检查覆盖旧版数据兼容、文件恢复、图片副本、大小和路径边界，以及不同屏幕宽度和便签数量的重叠边界。

Windows 构建执行 `QuickNote.exe --smoke-test artifacts/smoke`，验证顶部触发、0.2 秒收起、非抢焦点显示、剪贴板、自由定位、删除及多种宽度下的布局，并输出截图。打包后再次执行检查，并用 `--updater-smoke` 在独立的程序副本上验证真实父进程退出、EXE 替换、重启确认和启动失败回滚。检查只使用临时便签或程序副本，但界面检查会读写运行会话的剪贴板。

结果在 Actions 的 `Windows-UI-checks`、`Windows-Portable-checks` 与 `Windows-Updater-checks` 下载项中。不包含：搜索、标签、手动置顶开关、撤销、开机自启、多设备同步、OCR 或聊天记录自动导入。
