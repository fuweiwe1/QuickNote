# Windows 11 验收清单

CI 的 WPF 冒烟检查验证资源加载、真实剪贴板文字和图片、持久化、筛选、排序及删除撤销，并输出截图；以下项目仍需 Windows 11 桌面人工验收。

- 解压 Portable 包，在未安装 .NET 的电脑上启动。再次启动同一程序应呼出已有窗口。
- 打开浏览器、微信等普通窗口，晾衣绳保持可见；关闭置顶后允许其他窗口覆盖。
- 从微信复制中文、表情、多行文本，点击草稿本；内容完整出现，复制回微信时空格和换行保持。
- 从 Windows 截图工具、微信复制图片，以及复制资源管理器中的图片文件；收录后删除原文件、退出并重启，图片仍可查看和复制到聊天窗口。
- 空剪贴板、其他程序锁住剪贴板、不支持的文件、损坏图片、超过限制的图片或文字都有提示，应用保持可用。
- 悬停时纸张放大并扶正，移出后归位，复制及删除按钮仍可点击。
- 双击长文字后可完整查看、编辑和保存；图片详情可缩放和滚动。
- 删除时沿锯齿边分为两片下落；8 秒内撤销恢复原内容和位置；连续删除时撤销最近一张。
- 搜索支持中文及英文大小写；无结果时可清空；滚轮和箭头可翻到最后一张。
- 拖动便签调整顺序，重启后保留；拖入多张图片可连续收录。
- Ctrl+Alt+空格 呼出/隐藏；Ctrl+Alt+V 收录；快捷键冲突有提示。
- 收起不丢内容；隐藏后托盘可呼出；从托盘退出后进程终止。
- 100%、125%、150%、200% 缩放下检查清晰度及按钮；多显示器、负坐标、切换主屏、拔掉副屏后确认窗口可找回。
- Windows 关闭“动画效果”时，各动画不再播放。
- 模拟磁盘不可写时，修改失败有提示，原便签不丢失。

当前不包含：开机自启、多设备同步、图片 OCR、网页内容解析、聊天记录自动导入、定时清理、富文本，以及文件附件管理。
