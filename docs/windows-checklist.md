# Windows 11 真机验收

自动检查覆盖存储、旧数据兼容、自适应重叠、顶部展开/离开收起、非抢焦点显示、普通窗口上方显示和最小化后恢复。以下项目补充验证实际鼠标、桌面快捷键、多屏与缩放。

- 从系统托盘退出旧版，再运行 Portable 包；旧便签保留。启动时绳子收在顶部，没有导航、说明卡片、搜索、翻页按钮、置顶开关或撤销提示。
- 在浏览器、微信、编辑器等普通窗口打开时，鼠标移到屏幕顶部，绳子向下滑出并浮在当前窗口上面。
- 展开时不抢走正在输入的应用焦点；只有实际点击输入控件时才切换焦点。
- 移到便签间、草稿本或复制按钮仍保持展开；鼠标离开整个展开区域约 0.2 秒后，绳子整体缩到顶部并完全隐藏。
- 收起前快速移回取消收起；收起动画中移回顶部能顺滑展开，不出现闪烁或卡在半途。
- 查看/编辑详情、右键菜单、拖动排序时不意外收起；关闭操作后继续遵守离开延迟。
- Win+D、Win+M、任务栏“显示桌面”、最小化其他应用后，移动到顶部仍可重新展开；多次来回切换也能使用。
- 在 100%、125%、150%、200% 缩放、负坐标副屏和竖向排列显示器下，顶部触发区、绳子两端和鼠标命中位置正确。
- 从右键菜单切换显示器，绳子横跨所选屏幕宽度；拔掉目标屏幕后在主屏顶部可以展开。
- 收录 1、5、20、50 张便签，少时有自然间隔，多时自动重叠，最后一张完整落在右端以内。
- 按住纸面后卡片直接跟随鼠标，可移到绳子任意横向位置；松手自动吸附，其他卡片不移动。拖到屏幕外时落在最近的可用端点，重启和换分辨率后位置保留。
- 拖动时自动收起暂停；复制/删除/展开按钮仍正常点击；丢失鼠标捕获时取消拖动，不留下浮动副本。
- 从微信、截图工具、浏览器收录文字和图片，复制回微信保留空格、换行和图片；删除原图并重启后仍可使用。
- 点 × 后撕纸动画并直接删除，没有撤销提示；复制成功仅按钮短暂显示“已复制”。
- 损坏或超限内容有提示，磁盘不可写时保留原便签。
- Windows 关闭动画效果后，展开和收起立即完成，其他纸张动效也不播放。
- 右键草稿本、绳子或托盘可新写、选屏、退出；退出后进程结束。
- 从右键或托盘打开更新窗口，显示当前版本和类型；没有新版、网络断开、下载取消均有反馈，当前版本继续运行。
- 发布高于当前版本的正式 Release 后，应用可直接下载并重启，精简版仍是精简版，原便签和位置保持。
- 模拟哈希校验失败、目录不可写及新版不能启动，确认原 EXE 不被破坏或可恢复；查看更新时晾衣绳不自动收起。
